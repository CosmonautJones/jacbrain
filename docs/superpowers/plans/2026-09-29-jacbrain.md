# JacBrain implementation plan

**Goal:** publish a useful, tested foundation for versioned Jac engineering memory.
**Architecture:** local SQLite evidence graph and stdio MCP adapter, with a
separately executable Jac-native graph scaffold and live Jac MCP validation.
**Tech stack:** Python 3.11+, standard library, Jac 0.37.23.
**Spec:** [Architecture](../../ARCHITECTURE.md).

User requested creation and execution, including GitHub publication. Proceed
with that authorization. Independent Jac graph and prior-art research are
delegated; the reference service is implemented inline.

## Constraints and review focus

Preserve private data and M-Local team work. No model API spend. No novelty or
token-efficiency claims without evidence. Test version isolation, stale receipt
rejection, tiny budgets, dangling edges, and compiler/protocol failures.

## Tasks

- [ ] Evidence store and ingestion: tests for idempotent ingestion, distinct
  versions, explicit file boundaries and typed links; implement transactional
  SQLite records and lexical declaration extraction.
- [ ] Context API: tests for relevance, project/version isolation, graph
  expansion, budget enforcement and empty results; implement query packet.
- [ ] Validation loop: test failed/mismatched receipt rejection; implement real
  Jac MCP handshake, tool discovery and validate_jac. Record diagnostics and
  compiler-only promotion. Exercise valid and invalid real snippets.
- [ ] Agent interface: expose context/ingest/validate through CLI and stdio MCP;
  integration tests initialize, list tools and retrieve through the process.
- [ ] Jac scaffold: compile and run actual native graph tests separately.
- [ ] Portfolio release: README, architecture, schemas, prior art, roadmap,
  CI and license; review and publish CosmonautJones/jacbrain; verify remote CI.

## Two-track delivery

M-Local runs independently: inspect remote and dirty state; recover current
hosting without resetting data; identify true always-on hosting requirements;
validate release changes in an isolated clone; publish reviewable PR and
deployment evidence. A laptop tunnel does not satisfy always-on hosting.
